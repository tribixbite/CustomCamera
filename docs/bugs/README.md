# Bug Reports & Issue Tracking

This directory contains bug reports and issue documentation.

## Contents

- **BUG_REPORT.md** - Master bug tracking document (primary reference)
- **ADDITIONAL_BUGS_FOUND.md** - Supplementary bug discoveries
- **BUG_FIXES_*.md** - Bug fix documentation by date
- **BUG_FIXES_SUMMARY.md** - Consolidated bug fixes summary
- **NEW_BUGS_*.md** - Newly discovered issues by date
- **ISSUES.md** - General issues and technical debt

## Usage

**For reporting new bugs:**
1. Add to BUG_REPORT.md (master document)
2. Include reproduction steps, expected vs actual behavior
3. Reference commit hashes and build versions
4. Note device/Android version specifics

**For tracking fixes:**
1. Document fix in BUG_FIXES_*.md with date
2. Update BUG_REPORT.md status
3. Include commit reference and build version
4. Add validation/testing notes

These files will be consolidated into a single master bug tracking document in future cleanup.
